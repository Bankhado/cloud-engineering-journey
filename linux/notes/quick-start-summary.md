# Quick Start with Linux — Summary

**Course:** LabEx Quick Start with Linux  
**Status:** Complete

## What I Covered

- **User account management** — creating and modifying user accounts, attaching home
  directories to new users

- **File operations** — creating, modifying, copying, and deleting files within
  directories

- **Directory management** — creating and deleting directories, understanding the
  overall directory structure

- **Navigation** — moving through the file system, understanding the importance of
  the root directory and how everything branches from it

- **Permissions and security** — granting and revoking access, changing user passwords,
  understanding the role of power users and the sudo command
