# Cloud Engineering Journey

## About Me

I'm an IT professional with four years of enterprise experience across legal, healthcare,
and financial services. My work has been hands-on — Active Directory, Azure AD, Intune,
SCCM, and M365 in regulated environments where uptime and compliance aren't optional.

I'm now making a deliberate transition into cloud engineering. This repo documents that
transition from start to finish.
